# 第 70 课：订单诊断 API

统一入口是根目录 `main_api.py`，会话调用由 `services/agent_service.py` 负责，核心图位于 `workflows/diagnosis_agent.py`。

主流程：新问题 → prepare → model → 普通 Tool / 人工审批 → model → finish。

模型自主选择订单、支付、退款或规则工具；程序负责参数、身份、执行上限和审批校验。业务事实以 JSON Tool 的结果及更新时间为准，规则答案保留 RAG 引用，资料不足明确说明。

新问题按完整轮次保留历史，重置本轮执行机会；普通恢复和人工审批沿用原状态，不重做成功的前序工具。审批请求先独立存档，审批决定和模拟执行分节点。模拟取消只适用于待支付订单，不写 JSON 或业务数据库。

有限重试只处理临时系统错误；敏感执行异常不重试。没有执行追踪、用量费用、耗时、重试统计或运行日志。业务会话只在当前进程有效。

使用方法、全部接口和 JSON 示例见 [FastAPI 调用与断点](20-fastapi.md)。
