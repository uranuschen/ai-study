# 当前验证方式

按用户要求删除当前程序的 test 文件与对应缓存，并移除 Makefile 的 test 入口。验证使用临时离线核查，不在项目内新增测试文件。

本次离线核查覆盖：应用启动与 OpenAPI、资料预览、JSON 业务查询、固定订单流程、基础图、参数校验、路径范围、会话隔离、有限重试、RAG 引用、工具前暂停恢复、审批确认 / 拒绝 / 旧编号拦截以及防重复模拟。

资料入库使用纯内存替身核对 HTTP 到 Service 的调用，不实际写库。RAG 与 Agent 的模型回答由离线替身提供，不访问真实 LLM，不下载模型。语法检查只解析源文件，不生成缓存。

真实数据库、模型响应、向量入库与网络延迟仍需用户显式运行相关接口后验收，离线核查不代表外部服务已经验证。
